# Python Socket Chat

A simple real-time chat application built with Python using TCP sockets and multithreading.

## Features

- Multi-client TCP server
- Real-time messaging
- Thread-based client handling
- Console chat client
- Pygame graphical chat client
- Easy to understand and extend

## Technologies

- Python 3
- socket
- threading
- pygame

## Project Structure

```
.
├── server.py          # Chat server
├── client.py          # Console client
├── pygame_client.py   # GUI client built with Pygame
└── README.md
```

## How to Run

### 1. Start the server

```bash
python server.py
```

### 2. Start a client

Console client:

```bash
python client.py
```

or

Pygame client:

```bash
python pygame_client.py
```
